URKAL INK TATTOO

Página web estilo urbano y artístico para un estudio de tatuajes profesional, enfocado en mostrar portafolio, estilos de tatuaje y agendar citas rápidas.

Overview

Sobre el proyecto

Este proyecto fue desarrollado para un estudio de tatuajes que buscaba una presencia digital fuerte, estética y oscura, con una vibra profesional pero artística. La meta fue mostrar rápidamente estilos, trabajos del artista, precios aproximados y un botón directo para agendar citas.

El diseño está inspirado en tonos oscuros, rojos intensos, efectos urbanos y una navegación rápida para captar clientes desde redes sociales.
